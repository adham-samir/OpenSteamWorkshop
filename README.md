# OpenWorkshop

Find Steam games, browse their Workshop, and download mods on Linux and Windows.
No game installation required.

## Install

**Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/adham-samir/openworkshop/main/install.sh | bash
openworkshop-gui
```

**Windows** — [download the latest release](https://github.com/adham-samir/openworkshop/releases/latest)
and follow the [setup guide](docs/installation.md#windows).

## Features

- Search games and browse their Workshop catalogs
- Download mods and collections through SteamCMD
- Track mod updates with per-game folders
- Native desktop app and command line

Some games require a Steam account with Workshop access.
